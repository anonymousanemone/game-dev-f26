- [Held-out evaluation](held-out-final.md): completed 18-episode frozen comparison, with per-episode outcomes, failures, latency, usage, reservations and raw evidence.

Current submission summary: [EVALUATION.md](../EVALUATION.md). Independent review and fix response: [review.md](../review.md). Raw active and retained episode evidence lives in [playtrace](../playtrace/).

The redundant `reports/provenance/source-manifest.json` and `lepsius-provenance.json` were subsequently removed; their last retained versions are in commit `aee02a6`. The rubric requires credits/reuse terms and inspectable inherited-code changes, not these extra research reports.

Recover a file without changing the checkout, from the repository root:

```bash
git show 7e197733444f4a02178532e1aaca932bff535323:midterms/anonymousanemone/reports/PATH > /tmp/recovered-report
```

Historical links inside exported conversations are records of the old layout. Retained experiment reports and raw trial artifacts are not removed merely because they contain losses, provider failures or superseded prompts. Uncommitted session evidence is preserved.
